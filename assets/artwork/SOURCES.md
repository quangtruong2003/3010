# Paper diorama artwork

These transparent cutouts were created for this website with OpenAI ImageGen and are stored in `public/artwork/`:

- `paper-theater-shell-v2.webp` — static rear shell with roof, paper walls, backdrop, plants and stage floor.
- `paper-friends.webp` — rabbit and teddy paper sculptures.
- `botanical-letter.webp` — letter-section floral branch.
- `botanical-card.webp` — greeting-card floral arrangement.

The stage shell remains a separate static layer from the interactive opening envelope, supplied-photo frames and paper characters.

The V5 assets in `public/media/` were captured from the website's GSAP opening sequence. The GIF, WebM and MP4 use the same 132-frame, 5.5-second sequence. `anniversary-opening-poster.png` matches its first envelope frame; `anniversary-theater-final.png` matches its last stage frame and contains supplied photographs without an envelope. The website uses the video `ended` event before showing the invitation.
